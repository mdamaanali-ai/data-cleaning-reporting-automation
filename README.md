# data-cleaning-reporting-automation
A Streamlit-based data cleaning and reporting automation tool that supports CSV/Excel uploads, automatic profiling, missing-value handling, duplicate removal, text standardization, data quality analysis, interactive visualizations, and downloadable cleaned datasets and reports.
